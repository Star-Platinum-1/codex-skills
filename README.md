# Codex Knowledge Base

Local knowledge base for Codex, stored at `D:\codex\obsidian`.

## Classification

- `00-Inbox`: uncategorized captures and temporary notes
- `01-Projects`: active deliverables and repositories
- `02-Areas`: ongoing responsibilities and operating playbooks
- `03-Resources`: reference material and research
- `04-Archive`: completed or inactive material
- `05-Shared`: notes prepared for Feishu sharing
- `06-Skills`: evaluated Codex skills and plugins
- `99-System`: templates, indexes, and operating rules

## Flow

1. Capture new material in `00-Inbox`.
2. Classify it into the appropriate folder.
3. Record evaluated skills in `06-Skills`.
4. Copy or link share-ready notes into `05-Shared`.
5. Share `05-Shared` notes through Feishu.

The GitHub repository `Star-Platinum-1/codex-skills` is the shared source for reusable Codex skills. The local vault is the working knowledge layer; Feishu is the communication and sharing layer.

## Shared Repository

`Star-Platinum-1/codex-skills` is a public, reviewed catalog of Codex skills and plugin examples maintained by the team.
