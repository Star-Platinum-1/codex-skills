# Skill Registry

This note tracks skills discovered, reviewed, installed, and shared.

## Statuses

- `candidate`: discovered but not reviewed
- `approved`: reviewed for usefulness and safety
- `installed`: available in the local Codex environment
- `shared`: committed to the shared GitHub repository
- `rejected`: not suitable or unsafe

## Review Rules

1. Prefer official or actively maintained repositories.
2. Check the manifest, instructions, scripts, and external network actions.
3. Do not install skills that request secrets or unrelated destructive permissions.
4. Record the source URL and review date before sharing.
