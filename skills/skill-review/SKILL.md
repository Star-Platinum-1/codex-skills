# Skill Review

Use this skill to evaluate a candidate Codex skill before installing or sharing it.

## Review Steps

1. Identify the source repository, owner, license, and last update.
2. Read the complete SKILL.md and inspect referenced scripts and assets.
3. List required permissions, network access, file writes, and external side effects.
4. Test the smallest safe workflow in an isolated location.
5. Record usefulness, reliability, maintenance status, and risk.
6. Mark the candidate as approved, installed, shared, or rejected in the Obsidian Skill Registry.

## Output

Return:

- Source URL
- Intended use
- Installation path
- Dependencies
- Verification result
- Risk notes
- Recommendation

Never copy secrets, credentials, private documents, or unrelated personal data into a skill repository.
